# 第7轮修正方案

日期：2026-10-21。范围为用户最新六项反馈，继续在codex/connector-workbench工作，不提交或推送。

1. 消息画布只投影用户输入与最终助手输出；调用工具时的协议消息和返回值保留在对话处理过程，不生成独立画布节点。主线和分支父子关系跳过过程协议行，分支仍复制完整真实上下文。
2. 对话布局核对实际DOM网格，关闭右面板时删除占位列和空白。Git只由顶部入口手动打开，切换模式或会话不自动展开。
3. Git仅接受用户明确选择且设置本地目录的工作空间。移除应用当前目录的隐式替代；未选择时不请求Git状态，已归档项目不作为默认对象。
4. 设置默认类别围绕中心紧凑、均衡排布；展开后将类别与子节点居中，收起后回到类别总览；提供显式居中操作，保存用户拖动位置。
5. Skill以本项目实际可用工具判断可运行性。通用操作规程可直接使用；支持的文件/命令等工具用明确的本项目调用说明适配。宿主专有插件调用不伪装为项目工具，显示缺失能力并从AI可用技能列表排除；发现、列表、加载与能力状态使用一致结果。
6. 工具入口使用独立紧凑工具列表，逐项查看详情；移除原能力总览的类型/来源筛选、双栏全页和新增能力来源区块。能力来源仍由既有导入入口管理。

验收重点是实际桌面尺寸下无右侧空槽、Git默认关闭且不回退应用目录；只包含输入输出的画布；设置展开前后相机中心；可运行外部Skill触发本项目真实工具；工具弹窗不出现原能力总览。使用隔离工作空间、受控模型HTTP协议、真实文件/SQLite/Git/Tauri交互，保留截图与验证记录。
