# PID-20261020：连接器、自然通话与能力配置整合

> 最新实现与验收以[第7轮结果](revision-7-results.md)及[第7轮方案](revision-7-plan.md)为准：画布仅显示输入输出、Git默认收起且显式选择工作空间、设置节点展开居中、Skill工具适配与独立工具列表。早期图稿保留需求历史。

## 1. 产品目标

让用户围绕“与谁对话、使用哪些能力、允许哪些操作”组织桌面智能体。主界面减少重复入口，配置集中，复杂内容在弹窗内完成，语音通话可持续进行，并以统一的昔涟主题覆盖主窗口和桌面浮窗。

本版定义最初 11 项需求及用户后续修订：更多导航页、节点编辑反馈、可定制显示、紧凑布局和多画布删除。现有模块仅作为实现接入点；旧任务画布只补齐用户明确要求的删除管理，不将其计划、执行图、任务列表和任务详情复制为连接器。

## 2. 信息架构

沿用当前 Tauri 桌面端的窄导航栏。桌面宽度下栏宽为 80 CSS px，小于 960px 时为 68px；每个入口图标在上、名称在下。顶部保留项目头像，选中项使用粉色左侧指示线、半透明底色和金色星标。

主栏顺序：**连接器、对话、工作空间、能力、更多**。任务原位替换为连接器；搜索和独立工作流入口移除；工作空间与能力维持现版的相对顺序。

**更多**点击进入独立导航页 `/more`，用卡片网格收纳智能体、记忆、知识库、监控、日志和账号等入口；不再弹出浮动菜单。点击卡片进入对应页面，进入二级页面后主栏继续高亮“更多”，页头提供“返回更多”。**底部固定区**保留安全与审批图标、设置图标、后端状态灯。

更多导航页与能力导航页使用同一网格规则：桌面三列、窄窗口两列、最窄一列，卡片间距 20px。整个导航内容区在左侧窄栏以外的可用宽度内水平居中，标题说明与网格共用同一中心线；每行从左向右、再从上向下排列，尾行从第一列开始。桌面侧栏本身保留在左侧。更多是功能导航，能力是能力类别导航，两者不重复堆叠同一份列表。

插件若新增用户可操作的功能，该功能的入口加入“更多”，显示功能名称和所属插件，点击进入对应功能页面。插件安装、连接、启停、版本和权限仍在“能力 → 插件”管理。只贡献工具、Skill 或 MCP 而没有独立功能入口的插件，不凭空生成页面卡片；插件停用/卸载后移除其功能入口。

主内容沿用当前桌面页头：标题与简短说明在左，页面操作在右。移除初版预览额外添加的品牌文字区、工作台/系统分组标题、“我的空间”面包屑和仿窗口按钮。背景使用项目已有花瓣水波素材，浅色和深色均通过表面透明度维持可读性。

其中工作空间、日志、账号保持已有职责，本版只在必要时修正指向已移除页面的跳转。下表描述功能入口目标，不表示全部直接显示在主栏。

| 入口 | 目标 |
|---|---|
| 连接器 `/connectors` | 对话、智能体和资源绑定的无限画布 |
| 更多 `/more` | 智能体、记忆、知识库、监控、日志、账号的卡片导航页 |
| 对话 `/chat`、`/chat/:id` | 文字交谈、语音输入、呼叫小涟 |
| 能力 `/capabilities` | Skill、工作流、MCP、工具、插件的统一导航 |
| 智能体 `/agents` | 角色、用户提示词、模型与能力绑定 |
| 设置 `/settings` | 基础配置、安全控制、智能体偏好、能力目录、外观 |
| 监控 `/system` | 资源状态、Token 用量、桌面浮窗 |

移除任务页和搜索页的产品入口及显式路由；移除工作流、技能、插件的独立侧栏入口，将它们纳入能力。清理导航、快捷键、按钮、空状态、上下文栏、通知和初始化引导中的旧跳转。对已移除路径不另建兼容重定向；统一落入应用现有未匹配路由处理。

“搜索”指用户主动联网搜索页面及其入口。能力列表中的名称筛选、历史对话筛选仍是局部列表操作；AI 的搜索工具继续由智能体调用，API 配置归基础配置。

## 3. R01：连接器无限画布

### 3.1 空间布局

以当前选中智能体为中心，按固定语义方位初始化节点：

| 方位 | 节点 | 关系含义 |
|---|---|---|
| 左侧 | 多个对话，展示标题与最近交互 | 该对话绑定哪个智能体 |
| 中心 | 智能体，展示名称、头像、当前角色 | 资源与权限的使用主体 |
| 上方 | 安全约束、权限配置 | 约束作用于该智能体及其资源调用 |
| 右侧 | 能力、工具、模型、插件；能力内含 Skill、工作流、MCP | 智能体可使用的资源 |
| 下方 | 记忆、知识库 | 智能体可读取的上下文来源 |

左侧“任务”只表示一个有目标的对话，不新建任务执行实体。节点标题可为“准备项目演示”，实体仍为 conversation。连接器不提供“运行整张图”“生成任务 DAG”“批量执行节点”等按钮。

每张连接器画布显示一个中心智能体，可以为同一智能体保存多张不同显示配置的画布。顶部按名称切换画布，另有“管理画布”入口。画布 ID、智能体 ID 和对话 ID 分开，切换或删除画布不得拿当前智能体 ID 代替目标画布 ID。

默认视图显示已连接节点加候选资源入口。节点可拖动，连线跟随。提供平移、滚轮缩放、缩放比例、适应可见节点、回到中心、多选、解除连接和布局保存。缩放范围 25%～200%；手动移动后保留布局，点击“整理布局”才重排可见节点。

默认使用紧凑布局：普通节点宽 200～240px、高 64～80px；中心节点宽 220px；同列节点垂直间距 16～24px；中心与相邻节点边缘间距 48～64px。不通过缩小字体制造紧凑感。保留四方向语义，避免跨越空白大半屏的长连线。密集与舒展两档布局可选择，首次进入为密集。

### 3.2 连接行为

1. 点击“添加连接”或从资源端口拖向智能体。
2. 打开资源选择弹窗，按类型筛选并选择对象。
3. 保存后显示连线；模型节点同时显示它承担的用途，如“对话模型”“识图模型”。
4. 单击节点即高亮并打开对应编辑弹窗，Enter/Space 同样可打开；拖拽结束不触发弹窗。弹窗中可直接修改，保存后更新原节点的摘要；取消则保留原值。对话弹窗内另有“打开对话”进入对话。
5. 点击连线查看关系和来源，选择“解除连接”只解除关系，不删除对话、模型或知识资料。

可连接类型由契约限定。不同对话互连、模型连记忆等不产生业务含义，不能保存为关系。布局是视图数据，连线是业务绑定，二者分别持久化。

模型节点按用途绑定一个分级模型池或直接指定一个档案。池内可包含多个厂商的多个模型；直接指定档案时只使用该档案，绑定模型池时执行用户配置的降级顺序。已开始的模型请求固定所用池的配置版本；下一次请求读取最新绑定。正在执行的动作不因拖动节点而重启。权限变化在下一次工具执行前读取。

### 3.3 首次进入

没有智能体时显示“创建智能体”；已有智能体但没有关系时显示中心节点和四方向添加入口。页面不自动创建对话、不自动运行工具。

### 3.4 节点点击与编辑反馈

| 节点 | 点击打开 | 可直接修改 |
|---|---|---|
| 对话 | 对话设置弹窗 | 标题、关联智能体；可打开该对话 |
| 智能体 | 角色编辑弹窗 | 用户提示词、角色、模型选择 |
| 安全约束 | 权限编辑弹窗 | 三态权限与资源范围 |
| 模型 | 模型池/绑定弹窗 | 当前用途绑定的池或固定档案、层级顺序；显示本轮实际使用的厂商、模型与降级状态 |
| 能力/Skill/工作流/MCP | 对应能力管理弹窗 | 绑定、启用状态和该类配置 |
| 工具 | 工具权限弹窗 | 当前智能体可用状态及范围；工具内部定义只读 |
| 插件 | 插件管理弹窗 | 连接参数、启用和绑定 |
| 记忆 | 记忆集合弹窗 | 选择范围及可编辑记忆内容 |
| 知识库 | 知识库绑定弹窗 | 绑定集合与来源管理 |

调用项目同类弹窗和服务，不另造只在画布上生效的配置副本。保存成功才更新摘要；保存失败展示具体原因并保留编辑内容。共享模型档案与仅调整当前智能体绑定是两个明确操作。

### 3.5 显示范围

画布工具栏提供 **全部、仅对话、仅能力、自定义**：

- 全部：显示当前画布选定的全部节点类型。
- 仅对话：只显示中心智能体、对话和它们的连线。
- 仅能力：显示中心智能体与能力、工具、模型、插件，隐藏对话和上下文节点。
- 自定义：在显示设置弹窗中勾选对话、安全约束、模型、能力、工具、插件、记忆、知识库；可隐藏单个节点，控制连线、标签和布局密度。

中心智能体始终可见。隐藏节点时其连线一并隐藏；隐藏只是视图设置，不取消授权、不解除绑定、不影响执行。每张画布分别保存显示设置、隐藏节点、布局与视口；切换后恢复各自配置。适应视图只计算可见节点边界。

### 3.6 多画布管理与删除

“管理画布”弹窗提供 **连接器画布** 与 **历史任务画布** 两类列表。后者是本次明确要求的原任务画布删除入口，不恢复旧任务中心页面。列表显示名称、ID、类型、最后修改时间、是否当前打开及运行状态；每行均有删除操作，不能只有当前画布可删除。

- 删除当前连接器画布：确认弹窗显示目标名称和 ID；成功后切换到列表中下一张，若无下一张则回到前一张。
- 删除非当前画布：删除被点击行对应的 ID，当前画布及未保存的编辑保持不变。
- 删除最后一张：显示“还没有画布”和“新建画布”，不静默创建替代画布。
- 删除历史任务画布：完整删除对应图定义和专属画布数据；外部成果文件、对话、能力资源不随图删除。
- 图有运行中任务：显示“停止并删除”，执行取消并确认任务结束后删除；取消失败则显示实际原因，图仍保留。
- 删除请求失败：列表保留该条目并提示原因，不能先从界面消失后又在刷新时回来。

区分三个操作：**删除画布**删除画布实体及其视图数据；**从画布移除节点**只隐藏该画布上的引用；**解除连接**修改实际业务绑定。删除连接器画布不删除智能体及其全局业务绑定。批量操作只针对勾选的画布，确认列出名称/数量和运行状态；逐项显示实际成功与失败结果。

## 4. R02：语音输入与自然通话

### 4.1 输入区

输入框底部保留附件、麦克风、呼叫、发送四种图标操作。删除“开始语音输入”“与小涟语音对话”常驻文字，用 Tooltip 和无障碍名称说明用途，图标热区至少 40×40px。

- 麦克风：语音转文字，识别结果进入输入框，用户可编辑后发送。
- 呼叫：与小涟开始连续语音会话，连接成功后自然说话，无需逐轮点击录音、发送或播放。
- 听写和通话共用一个麦克风所有者。开启通话时结束听写并保留已有文本；通话中麦克风按钮表示通话静音状态。

### 4.2 通话状态和轮替

`未通话 → 正在连接 → 聆听 ↔ 思考 ↔ 说话 → 已结束`。

连接成功条件同时包含：会话已建立、麦克风已获取、所选识别及合成服务可用、音频输出可播放。点击后立即打开浮窗显示“正在连接”；在条件满足前不提前显示“通话中”。

用户说话结束后自动提交本轮语音；小涟自动回答并播报，播报结束继续聆听。用户在播报中讲话可打断当前回答，小涟停止旧音频并接收新的表达。通话需要处理扬声器回声，避免把自身播报识别为用户新话语。

通话的推理模型若绑定分级模型池，按池规则自动降级，并在浮窗显示简短切换提示。麦克风、语音识别或合成服务连接失败时显示具体原因与“重新连接”或“打开基础配置”，不擅自切换这些独立服务。首次系统麦克风授权属于设备权限，之后每轮无需再次确认。

### 4.3 浮窗

展开态约 320×380px：小涟头像、通话时长、当前状态、最近一句字幕，底部静音、扬声器、挂断图标。顶部有收起按钮。

收起态为直径 64px 的圆：中心头像、外圈声波/状态环、静音小标记。拖动可调整桌面位置，单击展开；右键菜单可直接静音和挂断。缩成圆不停止录音，挂断则释放麦克风、音频播放和服务连接。

作为独立 Tauri 浮窗，在主窗口最小化后继续通话。切换页面不创建新会话。浮窗和主窗口读取同一会话状态，只有一个音频采集与播放执行者。关闭整个应用结束会话。

通话绑定发起时的对话。用户浏览其他对话时浮窗显示当前通话的对话名；需要切换时使用“切换到当前对话”，避免一句话落入错误对话。

### 4.4 交付标准

真实麦克风连续对话至少 10 轮；完成自动轮替、插话、静音、挂断、页面切换、窗口最小化与圆形收起操作。收起与展开属于同一会话，已有上下文保持连续。

## 5. R03：移除用户搜索功能

删除搜索页、一级入口、快捷键和从其他页面进入搜索页的按钮。AI 需要搜索时通过工具调用，结果在对话中形成可读答复及来源。搜索服务地址、厂商、密钥、区域在“设置 → 基础配置 → 搜索”管理。

不保留一个换名后的用户搜索页；初始化引导也复用基础配置弹窗。

## 6. R04 与 R05：能力中心

### 6.1 导航和内容

能力首页按用户草图采用 **三列两行卡片网格**，不再使用顶部单排分类加最近列表的布局。六个入口为 **Skill、工作流、MCP、工具、插件、导入与本地发现**；第六个是操作入口，不伪装成新的能力类型。桌面卡片建议宽 260～320px、高 164～180px，间距 20px；标题和网格在内容区水平居中。

首页每张卡片展示图标、类别名称、一句用途说明和进入提示。首次进入不自动打开弹窗。点击类别卡片才打开对应管理弹窗；可通过弹窗顶部标签切换其他分类。列表占据弹窗剩余空间，有独立滚动条，标题、分类和底部操作固定。类别数量不由设计稿写死，实际计数由数据返回。

卡片只展示名称、一行说明、来源、状态与主要操作。长说明最多两行，详情中展示短摘要和“查看更多”纯文字按钮。点击“查看更多”打开文本阅读弹窗，支持文本选择、复制和正文滚动。

详细编辑、导入、连接服务均在弹窗内完成。复杂工作流编辑器使用大尺寸弹窗，内部画布平移与缩放；不强行把编辑器变为长表单。一个管理弹窗最多叠加一层阅读弹窗，编辑步骤用同一弹窗内的返回导航。

### 6.2 工作流

工作流从侧栏消失，进入能力的“工作流”分类后进行查看、创建、编辑和运行。保留工作流自身职责，不混入连接器。连接器中的工作流节点只表达“智能体可使用此工作流”。

### 6.3 布局约束

主页面无整页纵向滚动。1440×900 时标准管理弹窗约 960×680px；详情弹窗约 720px 宽、最大高度 80vh；工作流编辑弹窗不超过 94vw×90vh。小窗口采用 `min(设计宽度, 视口宽度-32px)`，正文区滚动，主要操作固定。

## 7. R06：统一基础配置

### 7.1 结构

设置中的“模型服务”“语音能力”合并为“基础配置”。基础配置使用七类服务入口：**对话模型、语音识别、语音合成、搜索、识图、生图、Embedding**。

每类显示当前绑定的模型池或服务档案、厂商及连接状态。模型配置主视图分为“已添加厂商”和“分级模型池”；添加/编辑厂商和模型在弹窗中完成，主视图直接显示池的层级顺序。其他服务点击卡片打开配置弹窗，不使用逐级折叠长页。

添加厂商弹窗选择官方预设、账户别名、区域和凭据；可连续添加多家厂商，选择新厂商不覆盖原厂商。厂商详情中添加多个模型档案。模型池通过引用这些档案形成层级，避免每个池重复填写密钥。高级参数在弹窗内独立标签页，保存和连接测试固定在底部。

### 7.2 预设与档案

选择官方厂商自动填入对应区域的地址、鉴权字段和可用服务类型。模型从厂商目录或维护的预设目录选择，支持填写模型 ID。不同厂商可以使用不同协议，不能只改变标签就宣称已接入。

所有产品已支持的官方厂商必须可直接选择。新增名单与完成规则见 [厂商文档](providers.md)。同一厂商允许多个账户和模型档案；识图和对话可使用同一厂商的同一模型，分别建立对应用途的档案并共用账户凭据。语音识别与合成可分别选择厂商。

搜索、图像、语音和 Embedding 的连接测试执行各自最小有效请求，不能只测试聊天接口。凭据输入支持粘贴、显示/隐藏、替换、清除；保存后显示“已保存”，再次打开不回填密钥明文。

### 7.3 配置状态

状态为未配置、待测试、连接成功、连接失败。保存配置与连接成功分别更新；连接测试结果属于该配置版本，修改地址、模型或凭据后重新测试。已保存档案可加入一个或多个模型池，再从连接器绑定给智能体。

### 7.4 多厂商分级模型池

每个池按用途配置，并命名为“日常对话池”“视觉理解池”等。级别表达用户优先顺序，不表示系统自动判断的模型能力高低。一级为首选，二级、三级依次作为后续候选；允许增加层级、上移/下移、拖动排序，以及同层添加多个候选。

调用按“一级内部顺序 → 二级内部顺序 → 后续层级”进行。上级遇到网络故障、超时、限流、额度不足、认证失败、模型不可用或服务错误时，自动尝试下一候选；跨层进入下一级时显示降级提示。每次请求中一个候选最多尝试一次，全部不可用时明确列出本轮失败原因并结束。

提示包含：原厂商/模型、目标厂商/模型、层级和原因。例如“一级 DeepSeek 连接超时，已切换到二级通义千问”。当前回复与连接器模型节点显示实际使用模型；通话浮窗显示简短提示。不能只在日志里记录，不能把下级模型的回复标成上级模型。

下一次独立请求从一级重新开始，若恢复则提示恢复首选；当前回答不因上级恢复而中途切回。用户取消、权限禁止、内容拒绝、参数错误不属于服务不可用，不以更换模型绕过。流式回答中断、工具调用与用量归属的具体规则见 [分级模型池开发细则](model-pools.md)。

本项自动降级是用户明确要求的产品功能；不扩展为对其他模块的自动修复、任意服务替换或备用实现。

## 8. R07：完整三态安全控制

用户可对默认策略、智能体、能力/工具、资源设置：

| 权限 | 实际行为 |
|---|---|
| 完全权限 | 在明确授权的对象和范围内直接执行，不重复逐次审批 |
| 需批准 | 执行前展示动作和对象，用户同意后执行当前请求 |
| 禁止 | 拒绝执行，不出现“批准后放行”入口 |

“完全权限”是有效授权，不得展示为完全权限却继续被旧 YOLO/Ask 配置悄悄改为逐次确认。设置界面需要展示授权范围；用户明确保存该权限构成对范围内操作的持续授权。系统自身能力、操作系统账户权限不因应用授权发生变化。

规则优先级：匹配的禁止规则优先；其余规则中更具体的资源规则优先于工具/能力规则，工具/能力规则优先于智能体规则，智能体规则优先于默认规则。同层冲突采用“需批准”优先于“完全权限”，并在界面显示冲突规则来源。

权限矩阵提供文件、进程/命令、网络、桌面控制、MCP/插件、记忆/知识访问等已有权限类别。每项可打开范围弹窗，指定目录、主机、服务或工具。权限判定由后端统一执行，文字对话、通话、工作流、MCP 都进入同一网关。

“需批准”弹窗展示完整动作、对象、作用范围，提供“本次允许”“拒绝”；持续授权通过安全配置显式修改。权限撤销后下一次调用立即生效；未执行的审批请求按最新规则重新判断。提供停止当前执行按钮，复用取消机制。

## 9. R08：外部能力导入与本地服务发现

统一入口：“能力 → 导入”，选项包括 Skill、工作流、MCP 配置、插件、本地服务发现。

- Skill：本地目录、ZIP、Git 仓库 URL；识别 SKILL.md 及资源目录，展示名称、说明、来源和安装位置。
- 工作流：导入产品定义的工作流 JSON，显示节点与所需能力，保存后在工作流列表中编辑和运行。
- MCP：导入配置文件，展示 stdio 或 HTTP 连接参数；凭据进入密钥存储。
- 插件：导入项目所支持格式的清单和资源，缺失格式适配必须作为开发内容实现。
- 本地服务发现：读取用户选定的目录、受支持应用的配置位置、已运行的本地监听服务；识别后展示服务地址、协议、模型或工具信息，用户选中导入。

发现流程为“选择发现范围 → 扫描 → 候选列表 → 选择 → 导入 → 连接测试”。本地服务发现不局限于手填 URL；应能发现并识别实际运行的本地模型或 MCP 服务。未能识别的候选可补充协议配置。

导入结果要能立即出现在对应分类，并可连接到智能体。重复来源展示“已导入”，版本不同展示差异并由用户选择更新。安装步骤中执行脚本、启动服务等操作遵循用户配置的三态权限，不额外建立另一套授权规则。

## 10. R09：用户提示词与角色扮演

智能体列表和详情不显示官方项目提示词，不提供编辑项目提示词入口。服务端公开 DTO 不返回该正文。

新增“用户提示词”和“角色设定”：

- 名称、头像、角色简介、语言与语气；
- 用户自由提示词；
- 是否启用角色扮演；
- 模型、能力和上下文资源绑定。

编辑使用弹窗；长提示词可点击“查看更多”在纯文本阅读弹窗查看。角色保存后影响该智能体后续文字与语音回复。对话中显示当前角色，允许切换角色；不把角色切换实现为新建后台智能体。

提示词组合顺序：项目执行约定、角色与用户提示词、绑定上下文、当前对话内容。角色控制表达、身份设定和回复风格；权限仍由执行网关读取配置。用户自己创建/导入的指令归用户内容，不因隐藏官方提示词而一并消失。

## 11. R10：Token 用量与监控浮窗

监控增加输入 Token、输出 Token、总 Token 和按日趋势，支持今日、近七天、自定义时间段与模型筛选。范围使用用户本地时区。

输入/输出分项按厂商上报统计。缓存命中等细分项只有数据存在时展示；不能把缓存 Token 再加到已经包含它的总量。未返回 usage 的请求显示“用量未返回”，不计为零用量。失败请求如已产生厂商用量，仍计入。

“开启桌面浮窗”显示当前 Token、CPU、内存和执行状态，支持选择显示指标、拖动、置顶和收起。收起为 64px 圆形状态球，点击展开为紧凑面板。语音通话和监控复用浮窗容器机制，但各自管理内容与开关；只有通话可占用麦克风。

两个浮窗同时开启时自动避开彼此的初始位置，后续位置由用户控制。给未来桌宠保留显示模块接口，本版不加入桌宠形象、养成系统或额外代理。

## 12. R11：主题、透明度与可读性

覆盖浅色、深色、跟随系统和自定义背景；沿用项目现有昔涟粉、浅紫与深紫语义色，不新增另一套品牌主题。

全局容器使用统一的页面、面板、悬浮层、输入层 token。主页面允许背景透出；设置表单、阅读弹窗和审批内容使用更高不透明度，文字不随面板透明度一起降低。

外观设置提供面板透明度和背景模糊度。透明度改变的是表面颜色 alpha，不使用父容器 `opacity`。画布、节点、下拉菜单、弹窗、Tooltip、滚动条、遮罩和独立桌面浮窗均响应主题切换。

正文字号 16px，控件 14px，辅助文字 13px；正文对比度至少 4.5:1。主题切换后不出现白底暗字残留或透明到难以阅读的输入区。

## 13. 方案选择

本版采用“薄主页面 + 管理弹窗 + 独立通话/监控浮窗”。它符合用户对短页面、自然通话与桌面陪伴的要求。

不采用把所有模块同时铺入一个巨型画布的方案：连接器需要清楚表达关系，不承担所有业务编辑。也不继续使用长页面折叠面板：编辑内容增加后仍会产生整页滚动。

## 14. 成功条件

11 个需求组均能对应实际页面操作、后端行为或桌面窗口行为。最终验收包含真实厂商连接、真实导入、真实权限执行、连续语音与实际用量统计；截图和自动化用例是证据的一部分，不能代替这些流程。
