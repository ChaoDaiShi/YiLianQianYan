## 桌面外壳修订

本版预览已按用户提供的当前 Tauri 桌面截图修正，并核对 `NavRail.tsx`、`AppShell.tsx`、`PageShell.tsx` 和 `workspace.css`。保留 80px 深紫窄栏、图标上文字下、顶部项目头像、底部安全/设置/状态灯和现有花瓣水波背景。根据最新要求，更多改为独立导航页，能力首页改为三列两行入口卡片。上一版展开侧栏与更多弹层都不作为开发依据。

2026-10-20 设计核对时，独立浏览器访问 `http://localhost:1420/tasks` 未取得桌面控制会话，页面停留在初始化提示；这不是用户桌面会话的运行结果。本次参考依据是用户桌面截图、当前源码和项目已有素材。

## 本版约定

- 沿用用户称呼“PID”，本文件集用于定义产品需求、交互和开发方案。
- 2026-10-20 为需求与预览阶段；2026-10-21 已按用户授权开始修改应用代码。实现范围与当前验证状态以 [实现报告](implementation-report.md) 为准，Git 交付状态由主执行者最终核对。
- 能力与更多导航整体居中，卡片按行从左向右、再从上向下排列；末行从第一列开始。
- 用户文字需求优先于草图中的旧布局：对话在左、安全在上、能力资源在右、记忆和知识库在下。
- “不涉及旧功能”按以下范围执行：不重写旧功能说明、不把旧任务中心搬入连接器、不扩展无关业务；后续明确要求的原任务画布整图删除，作为针对性修复纳入 D02。
- 用户已明确要求模型池自动降级，本版按该要求实现并显示切换提示；不扩展到其他模块的自动修复、任意替换或双轨兼容。
- 安全控制本身是第 7 项明确要求，必须完整接入执行过程。
- 2026-10-21 用户授权使用子智能体实施，主执行者负责共享入口和集成验收。
- 验收以可复现的实际操作与结果为准；测试数据可以用于自动化，但不能替代真实服务、麦克风和桌面窗口验收。
