# 验收清单

2026-10-21 已进入产品实现与集成验收。本文保留逐项验收标准；当前代码接入和验证记录见 [实现报告](implementation-report.md)。未填写实际结果的项目均为待执行，不能根据代码存在、设计预览或用例数量推定通过。

每条记录：构建版本、环境、操作步骤、实际结果、截图/日志/录屏位置、结论。结论使用“通过 / 未通过 / 待执行”；若缺少厂商账号或设备，记录具体缺项和受影响编号。

## N：导航与页面移除

| N02 | 检查上下文栏、对话摘要、空状态、通知、初始化引导 | 无跳转至被移除页面的控件；搜索配置进入基础配置 |

| N06 | 查看能力/更多导航，比较网格到内容区左右边界的距离 | 标题与网格中心一致，左右留白相等；按行从左向右、再从上向下排列，尾行不足三项时从第一列开始；桌面窄栏位置不变 |

## C：连接器

| 编号 | 操作 | 通过标准 |
|---|---|---|
| C01 | 初次进入有多个对话的智能体 | 对话左、智能体中、安全上、能力工具模型插件右、记忆知识下 |
| C02 | 平移、缩放、移动节点后离开并返回 | 节点位置和视口恢复；缩放范围 25%～200% |
| C03 | 绑定一个模型和一项工具，发送对话请求 | 实际使用选中模型/工具；连线不只影响画面 |
| C04 | 解除一条绑定 | 下一次调用不再使用该绑定；原资源和对话仍存在 |
| C05 | 拖动不支持的节点关系，例如模型到记忆 | 不保存无意义关系；界面说明可连接对象 |
| C06 | 切换中心智能体 | 显示各自的关系、布局和约束，不串用其他智能体配置 |
| C07 | 检查主画布和管理弹窗 | 主画布无旧任务执行列表、计划生成、任务 DAG 和“运行整张图”；管理弹窗只为历史图提供画布级管理与删除 |
| C08 | 分别点击每一种节点，另用 Enter/Space 激活 | 打开对应编辑弹窗；保存更新摘要，取消不改值，拖拽不误触 |
| C09 | 切换全部、仅对话、仅能力，再自定义类型 | 中心始终显示；只显示所选类型与两端可见的连线；实际绑定不变 |
| C10 | 同一智能体创建两张画布，保存不同显示与布局并重启 | 每张按 canvas_id 恢复配置，修改一张不覆盖另一张 |
| C11 | 恢复密集布局并测量距离 | 相邻节点边缘 48～64px、同列 16～24px；字号保持可读；舒展可切换 |
| C12 | 从画布移除节点、恢复显示，再解除连接 | 移除仅影响视图；恢复仍有绑定；解除连接才影响后续业务使用 |

## D：多画布删除

| 编号 | 操作 | 通过标准 |
|---|---|---|
| D01 | 打开 A，在管理列表删除非当前 B | DELETE 目标为 B；A 的画布、视口和未保存表单不变；C 保留 |
| D02 | 删除当前 A | 按列表顺序切换到下一张或前一张；不会停留在失效页面 |
| D03 | 删除最后一张 C | 列表为空，显示新建入口，不自动创建替代画布 |
| D04 | 删除一张历史 TaskGraph，刷新并重启 | 图定义、专属视图与可变从属数据删除；runtime 不再返回；列表无此图、GET 返回 404；外部产物与对话保留 |
| D05 | 删除运行中的历史图，选择停止并删除 | 等待实际执行结束后删除；取消失败则保留图并显示原因 |
| D06 | 注入删除 API 失败、版本改变；同时从另一视图访问该图 | 失败保留列表项；冲突要求更新后确认；成功删除后其他视图不能保存或执行旧图 |
| D07 | 勾选 B/C 批量删除，其中 C 失败 | B 删除、C 保留并显示失败原因，未勾选 A 不变 |
| D08 | 在名称/提示词输入框按 Delete，再删除节点/连线 | 文本输入不触发画布删除；节点移除、连线解除、整图删除三个操作明确区分 |

## V：通话

| 编号 | 操作 | 通过标准 |
|---|---|---|
| V01 | 查看输入框，鼠标悬停/键盘聚焦两图标 | 无常驻语音按钮文字；Tooltip 和读屏名称清楚 |
| V02 | 点击呼叫，观察网络与设备建立 | 立即显示正在连接；准备完成后进入聆听；时长从连接完成起算 |
| V03 | 真实麦克风连续交谈 10 轮 | 无逐轮点击录音/发送/播放；上下文连续，回复自动播报 |
| V04 | 在小涟播报时插话 5 次 | 旧音频停止，新话语被接收；无残余旧答案继续播放 |
| V05 | 使用扬声器通话、静音、解除静音 | 不把自身播报当用户新请求；静音时不上传用户音频 |
| V06 | 收起成圆、拖动、再展开 | 会话 ID 不变；圆形状态能显示聆听/说话/静音 |
| V07 | 切页面、切对话、最小化主窗口 | 通话持续；原对话归属明确；浮窗在桌面可用 |
| V08 | 挂断、连接失败、重新连接 | 挂断释放麦克风与播放；失败给出原因；重连由用户触发 |

建议体验指标：点击后 100ms 内出现连接态；局域设备和可用网络条件下连接时间 P95 ≤ 5s；语句结束至第一段回答音频 P95 ≤ 3s；插话至停止旧播放 P95 ≤ 300ms。记录使用设备、网络、厂商、模型与样本数。未达到指标时定位断句、识别、模型或合成耗时并修正，不能通过改成手动按键通话规避。

| B04 | 保存、重开、替换、清除密钥 | 保存成功；重开不回填明文；保留与清除语义明确 |
| B05 | 分别测试聊天、STT、TTS、搜索、识图、生图、Embedding | 每类完成实际有效请求并呈现结果 |
| B06 | 修改已通过测试的模型/地址/密钥 | 旧连接结果不再显示为当前配置成功 |
| B07 | 从现有配置升级后发起请求 | 使用原地址、模型与凭据；不丢失已有配置 |
| B08 | 从连接器为某智能体选择专属档案 | 该智能体实际使用专属档案，其他智能体默认档案不变 |
| B09 | 连续添加三家厂商，同厂商再添加一个账户 | 账户、凭据与模型独立保存；添加操作不覆盖已有项 |
| B10 | 建立两级以上模型池，调整层级和同层顺序 | 持久化顺序一致；实际调用按层级及同层顺序；不并发竞速 |
| B11 | 一级返回超时、429、5xx，二级正常 | 自动切换二级并完成回复；提示原模型、原因、目标和层级；Token 归属实际请求 |
| B12 | 一级认证失败/额度耗尽/模型不可用，二级正常 | 分类准确、自动降级并提示修复对应配置；不将任意 4xx 统称为可用性失败 |
| B13 | 全部候选失败或到达总时限 | 每候选本轮最多一次；显示汇总并结束；不无限重试或偷偷新增厂商 |
| B14 | 一级部分流输出后断开，二级继续 | 原片段标记中断，新回答明确更换来源并替换正文；不拼接残句 |
| B15 | 工具已执行成功，后续推理模型失败 | 降级只影响后续模型调用，已完成工具动作不重复执行 |
| B16 | 调用中取消，或出现权限禁止/内容拒绝/请求参数错误 | 不为这些原因换模型；取消后不启动下一候选 |
| B17 | 上轮使用二级，恢复一级后发起新请求 | 新请求优先一级，成功后显示恢复提示；旧回答不被中途换回 |
| B18 | 给智能体绑定模型池，再在另一个智能体固定档案 | 前者按池调度，后者不自动换到其他模型；对话/通话/连接器/监控的实际来源一致 |

## S：三态权限

| 编号 | 操作 | 通过标准 |
|---|---|---|
| S01 | 对测试目录写入配置完全权限，连续执行两次 | 两次均实际写入，无重复审批 |

| S06 | 审批等待期间改为禁止/撤销授权 | 未执行请求读取新规则，不沿用旧批准执行 |
| S07 | 从文字、通话、工作流和 MCP 执行等价操作 | 相同主体/资源得到相同规则结果 |
| S08 | 执行时点击停止 | 取消现有可取消动作，后续队列不再启动 |

使用专门测试目录、测试命令和本机测试服务观察结果；这不降低权限引擎或业务路径要求。
