# 消息渠道与回复预设

入口位于桌面端“更多 → 消息渠道”（路由 `/channels`）。配置飞书、QQ / OneBot 11 或微信 iLink 后，名单内联系人发来的私聊文本会由真实模型生成回复。每个渠道可选择“自动回复”或“审阅后发送”：自动模式生成后直接发送，人工模式可以先编辑正文、查看本地对话再批准发送。

新建渠道默认选择自动回复。已有渠道保持原来的方式，可在渠道详情点击“开启自动回复”切换；切换不会批量发送已有待审阅草稿。自动发送单独记录 `send_mode=automatic`，不会伪造用户批准时间。结果未知的消息仍不会自动重发。

## 选择接入方式

| 平台 | 接入配置 | 使用前提 |
| --- | --- | --- |
| 飞书官方长连接 | App ID、App Secret、允许用户的 open_id | 自建应用开启机器人与消息权限，订阅私聊事件并发布；不需要公网回调 |
| 飞书 HTTP 订阅 | 上述配置加 Verification Token | 平台能访问的 HTTPS 回调；本机相对路径不能代替公网地址 |
| QQ / OneBot 11 HTTP | HTTP API 地址、self_id、Access Token、事件签名 secret、允许用户数字 ID | 用户独立运行并登录 OneBot / NapCat，配置签名 HTTP 事件上报 |
| QQ / OneBot 11 反向 WebSocket | self_id、Access Token、允许用户数字 ID | 外部服务连接页面显示的反向 WS 地址，发送 Bearer token 和 X-Self-ID |
| 微信 iLink | 新建渠道后选择“开始扫码”，在微信完成授权或数字验证码 | 首次允许名单留空时，只加入平台返回的扫码用户；授权完成后还需启用收信 |

OneBot 页面生成的是当前后端的本机地址。同一电脑的服务可以直接使用；其他电脑的服务需要配置实际可达的主机地址。应用不会替用户安装或登录 QQ，也不会自动改换连接协议。

## 回复预设

内置“昔涟 · 温柔日常”“简洁工作助手”和“学习答疑”。内置模板可以复制成自定义预设，再修改名称、关联角色、模型档案与回复提示词。角色和模型使用现有配置，不另存模型凭据。

保存预设后可以输入一条试用消息，调用真实配置的模型生成本地结果。试用不会向平台发消息。模型未配置、凭据不可用或平台拒绝请求时，页面显示实际错误。

为渠道改选预设后，随后开始生成的消息使用新预设；已经生成的草稿保持原文。外部渠道仍没有本机文件、桌面、工具、私人知识库或其他会话权限。

## 理解状态

- **已配置**：配置已经保存，尚无连接或事件成功的观察。
- **已连接**：长连接或长轮询已有成功结果，不代表已收到消息。
- **已收到有效消息**：收到并持久化了名单内的有效私聊文本。
- **草稿待审阅**：人工模式下模型已完成回复，可以编辑和逐条批准；切换到自动模式前留下的草稿也保持此状态。
- **自动回复 · 平台已确认受理**：新入站消息已经完成模型生成和自动发送，无需本地逐条批准。
- **平台已确认受理**：平台返回成功。飞书 / OneBot 使用平台返回的消息 ID；微信使用平台已接受请求的 client_id。均不代表联系人已经阅读。
- **送达状态未知**：请求已经发出，但没有取得明确结果。请到平台核对，页面不会提供直接重发按钮。

“检查连接”分别报告本机凭据、允许联系人、平台账号认证与运行连接。HTTP 账号认证成功不能证明事件回调可达。图片、文件、语音、混合内容和群聊属于本次私聊文本接入范围之外，最近诊断会说明未触发模型的原因。

停用会停止连接和未完成的草稿处理。删除会停止渠道、清除凭据、渠道收件箱及会话关联，已有本地对话与聊天消息保留。若有发送仍在等待回执，需先等待结果明确。
