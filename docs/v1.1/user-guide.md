# YiLianQianYan v1.1 User Guide

## First start

首次启动进入五步向导：身份、模型、搜索、语音和完成。身份、Search Key、STT 与 TTS 可以跳过；文字智能功能需要一个已保存且验证可用的模型连接。点击“稍后完成”只延后向导，不会禁用本地功能。

## Guest and account

Guest 模式显示“仅本地”，可以使用对话、任务、画布、MCP、Voice、记忆、资源和设置。登录或注册后，账号中心显示当前设备和其他会话。退出登录清除本机云会话，不删除本地工作数据或云端账号。

登录后必须选择现有本地数据的处理方式：

- 同步已有数据：扫描已选择的本地实体，写入 Outbox 后增量上传。
- 保持仅本地：账号保持登录，但不上传工作数据。
- 稍后决定：同步按钮保持不可用，直到用户明确选择。

## Sync Center

同步中心显示待同步数量、冲突、失败、cursor、最近成功时间和错误码。点击“立即同步”先采集本地变更，再 push Outbox，随后从 cursor 增量 pull。云端暂不可用时，本地变更不会丢失。

冲突不会静默覆盖。选择“保留本机”会基于云端 revision 创建新变更；选择“采用云端”只在云端 payload 或删除墓碑完整时可用。

## Data and Privacy

Data and Privacy 只展示云端实体数量和对象占用，不读取正文。用户可以请求导出或永久注销账号。注销必须输入 `DELETE`，云端会撤销所有会话并创建可追踪 DeletionJob。本机数据和本机 Provider Secret 是否清理仍是独立选择。

## AI Search

AI Search 默认可使用 AnySearch 匿名额度。用户可以在“搜索服务配置”中写入本机 API Key。搜索结果支持：

- 打开真实来源；
- 将标题、摘要和来源送入小涟编辑框；
- 创建研究任务；
- 保存为知识类长期记忆。

若搜索失败，界面显示安全归一化错误，不显示 Provider 原始响应或凭据。
