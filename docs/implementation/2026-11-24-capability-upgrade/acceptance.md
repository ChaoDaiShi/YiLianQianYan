# 系统能力升级验收矩阵

2026 年 11 月 24 日，分支 `feat/personal-proactive-assistant`。需求来源为同目录的 [v1.0 开发说明书](requirements.md)。本轮以原工作树为基础，起始提交为 `2817d110`。下表按第 19 章的用例逐项记录证据范围。

| 用例 | 已执行的验证 | 边界 |
| --- | --- | --- |
| AT-01 首次初始化 | Edge 通过真实 HTTP 完成七步向导，读回称呼、字段修改时间和单项授权。可保存进度离开到聊天。 | 模型连接和个人字段均可稍后设置。 |
| AT-02 中断恢复 | 浏览器重新进入向导读回文本，SQLite 关库重开时恢复步骤、草稿和版本。过期提交返回 409。 | 草稿中的授权在明确提交后生效。 |
| AT-03 API 切换 Codex | 真实 Codex CLI 在同一忆涟会话找回前一轮测试标记。核对消息游标、轮次回执和用量。 | API 对照端为回环夹具；Codex CLI 使用实际传输。 |
| AT-04 CLI 中断 | 受控 Gemini JSONL 子进程在真实 HTTP 流程中撤权取消，同一对话后续轮次从本地已提交历史恢复。 | 未使用真实 Gemini 账号；未验证第三方原生线程原位续接。 |
| AT-05 互动图表 | Edge 通过本地受控模型生成包含图表、图片、表格、表单和任务的回复；提交的状态从真实后端读回。 | 外部协议覆盖已实现的 AG-UI 和 A2UI 子集。 |
| AT-06 关闭重开 | 实际重启隔离后端，再打开保存的页面、聊天来源、提交状态和 AI 提案结果。 | 渲染验收使用 Edge。 |
| AT-07 语义检索 | CPU 上实际运行 BGE-small-zh-v1.5，受保护 HTTP 验证 512 维输出、范围过滤和混合检索。 | 四条人工标注查询仅用于小样本回归。 |
| AT-08 更新旧记忆 | 核对当前修订、过期和撤回过滤；改变记录后旧向量不能继续作为当前修订使用。 | 历史修订作为可审阅记录保留。 |
| AT-09 多级页面 | 浏览器创建三级页面，自动保存并刷新；循环移动返回 409。分页、按父级读取、搜索、回收恢复和 Markdown 往返有路由测试。 | 三层是实际浏览器样例深度。 |
| AT-10 AI 页面协作 | 页面修改先审查再应用，恢复旧修订可撤销。重试创建及修改幂等；页面引用、固定页面版本生成草稿任务和跨工作区拒绝均有回读断言。 | 页面内容由现有 Markdown/块编辑接口处理。 |
| AT-11 桌宠任务反馈 | 真实后端工作流节点进入 succeeded，经 SSE、主界面桥和桌宠组件显示“工作流步骤完成”，随后按时间清除。 | 无头 Edge 中仅 Tauri 外壳使用夹具。 |
| AT-12 拒绝截屏 | 真实桌面聊天入口和原生 IPC 都返回未授权，页面没有生成图像预览。 | 测试账号及应用数据独立。 |
| AT-13 采集中撤权 | 旧构建实测复现选择器等待期间撤权后请求仍挂起。修正后对生产协调逻辑注入等待中的选择和帧，两条路径均主动释放资源、返回零字节；独立 WGC 实测成功捕获专用合成窗口。 | **部分通过**。修正后 Windows 系统选择器的真实自动消失、真实 GPU 帧等待中撤权仍未实测。用户注意到真实桌面的系统选择器后，后续验证使用受控等待。 |
| AT-14 Wallpaper Engine | 从真实桌面设置打开专用合成视频预览窗，观察实际引擎窗口出现，再按名称关闭。显示器原壁纸路径与引擎原配置摘要前后一致。 | 全局播放与暂停没有作为可回读状态验收。 |
| AT-15 外部引擎退出 | 临时 Lively 进程在发现后正常退出，桌面设置的旧操作被拒绝，刷新后移除播放操作。 | 使用受控进程模拟故障，原 Wallpaper Engine 及显示器配置保持一致。 |
| AT-16 插件退出 | 实际启动托管插件测试子进程，使其以 23 异常退出。后端记录 exited/23，主服务健康接口和 SQLite 继续可用。 | 另有停用、健康降级和子进程树回收测试。 |
| AT-17 模型并行 | 两个不同模型档案分别在同一主会话的两个子会话发起请求。回环端点用屏障确认请求时间重叠，随后读回两个完成状态与独立消息，对话正文未串线。 | 两个确定性模型响应由受控回环端点提供。 |
| AT-18 索引重建 | 删除测试库的派生向量并重启，重新使用真实 BGE 生成向量，记忆 ID、原文保留。 | 当前向量通过 SQLite 派生字段保存。 |
| AT-19 升级旧库 | 升级前的后端建立隔离旧档案，使用交付后端启动、迁移并核验历史会话、消息和设置。将备份另存后再次检查原结构与数据，两份库均通过完整性和外键检查。 | 这是实际数据升级与恢复；在干净 Windows 环境覆盖旧安装包是另一项验收。 |
| AT-20 桌面组件异常 | 在真实 WebView2 窗口触发测试组件渲染进程崩溃，Explorer 的 HWND/PID 未变且仍能响应。重新打开隔离应用后再次操作组件成功。 | 未重启正在使用的 Windows Explorer。 |

## 发布边界

本机没有可用的隔离 Windows 安装环境。NSIS 安装包的构建、签名状态和 SHA-256 可验证，正式安装、覆盖旧版和卸载流程仍需在干净 Windows 账户或虚拟机验收。真实 VTube Studio、Rainmeter、Lively、Gemini 账号的完整联调各有单独的运行环境要求。桌面功能保持独立开关。
