# 忆涟千言 v1.1 服务化路线（冻结规划）

状态：`DOCUMENTED_ONLY`

本文件只冻结 v1.1 的方向、边界和阶段，不授权在 v1.0.0-rc.2 中实现 Identity、Cloud Model Gateway、Cloud Harness 或 Web Surface。

## Theme

```text
服务化
```

## Core directions

- Optional Identity
- Cloud Model Gateway
- Cloud Harness
- Web Surface

## Optional Identity

账号必须保持可选。未来支持两种身份状态：

```text
Guest
Authenticated
```

允许组合：

```text
Guest + BYOK
Authenticated + YiLian Cloud
Authenticated + BYOK
```

Cloud 是可选能力，BYOK 始终是一等路径。未登录用户仍可使用本地能力和自带 Provider，不得通过强制注册破坏 local-first 产品边界。

## Cloud Model Gateway

未来云模型访问链路：

```text
Desktop / Web
↓
YiLian Access Token
↓
Cloud Model Gateway
↓
Auth / Entitlement / Rate Limit / Usage
↓
Provider
```

Provider Key 永不发送到客户端。客户端只持有忆涟访问令牌；Gateway 负责身份、权益、限额、用量、Provider 路由和服务端秘密管理。

BYOK 继续通过现有安全路径独立存在，不能因为 Cloud Gateway 上线而被降级或强制迁移。

## Cloud Harness

Cloud Harness 是可选的远程执行/协调能力，不替换本地 Task Harness、Security Gateway、ApprovalStore 或本地审计。远程执行必须显式标识执行位置、权限、费用、取消语义和可验证结果。

## Web Surface

Web 是 Surface，不是第二套 Agent Runtime：

```text
YiLian Harness
↓
Projection / Command / Events
↓
API Gateway
├ Desktop Surface
└ Web Surface
```

Desktop 与 Web 消费同一任务、命令、事件和投影契约；不得复制一套独立 Agent、审批状态机或伪造的 Web 执行状态。

## Recommended phases

### Phase 1 — Identity Foundation

- Guest/Authenticated 状态和可撤销访问令牌；
- 本地数据与云账号边界；
- 不登录时的完整降级语义。

### Phase 2 — Cloud Model Gateway

- 服务端 Provider Secret；
- entitlement、rate limit、usage 与审计；
- YiLian Cloud / BYOK 明确切换。

### Phase 3 — Cloud Harness

- 可选远程执行；
- 任务状态、取消、审批与验证契约；
- 与本地 Harness 的执行位置分离。

### Phase 4 — Web Surface

- 通过 API Gateway 消费 Projection / Command / Events；
- 不复制 Agent Runtime；
- 明确浏览器权限和不可用能力。

### Phase 5 — Cross-Surface Experience

- Desktop/Web 会话与任务连续性；
- 一致的状态、历史和成果引用；
- 冲突、离线和重连处理。

## rc.2 non-goals

v1.0.0-rc.2 不实现：

- 账号注册或登录；
- 云访问令牌；
- Cloud Model Gateway；
- Cloud Harness；
- Web Surface；
- 云同步、跨设备同步或云计费。
