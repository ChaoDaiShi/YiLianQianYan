# 忆涟千言 v1.1 用户云与体验版路线

状态：`IN_IMPLEMENTATION`

本文件最初记录的“服务化路线”已由 2026-10-06 的 v1.1 用户云与体验版规划修订。当前实施基线记录在 `docs/v1.1/baseline.md`，详细阶段记录在 `docs/superpowers/plans/2026-10-06-v1-1-user-cloud-experience.md`。

## Theme

```text
用户云与体验版
```

## Core directions

- Optional Identity
- Incremental Cloud Sync
- Account Privacy and Lifecycle
- AI Search
- Private Admin

## Optional Identity

账号必须保持可选。未来支持两种身份状态：

```text
Guest
Authenticated
```

允许组合：

```text
Guest + BYOK
Authenticated + YiLian Cloud
Authenticated + BYOK
```

Cloud 是可选能力，BYOK 始终是一等路径。未登录用户仍可使用本地能力和自带 Provider，不得通过强制注册破坏 local-first 产品边界。

## Cloud Services

v1.1 云端提供 Identity、Sync、User Data、Search Proxy、Export 和 Delete 服务。模型与 Voice 继续优先使用本机 BYOK；v1.1 不实现 Cloud Model Gateway。

AnySearch 支持匿名、本机 BYOK 和未来 Cloud Search Proxy。平台 Search Provider Key 永不发送到客户端。

## Deferred capabilities

Cloud Harness、远程 Computer Use、多人实时协作、企业组织、订阅计费和完整 Web Surface 均延后到 v1.2 或独立立项。v1.1 云端故障时必须退化为 local-only。

## Recommended phases

### P0 Foundation Freeze

- 冻结 ADR、公开契约、同步协议和公共/私有代码边界；
- 创建 `v1.1/base` 与物理隔离的私有本地仓。

### P1 Optional Identity

- Guest/Authenticated 状态和可撤销访问令牌；
- 本地数据与云账号边界；
- 不登录时的完整降级语义。

### P2 Private Cloud Data

- 私有 Cloud API、PostgreSQL、用户数据和对象 metadata；
- 私有源码不进入公共仓。

### P3 Incremental Sync

- outbox、cursor、revision、tombstone 和 conflict；
- 离线工作与恢复后增量同步。

### P4 through P8 Product Surfaces

- Account、Sync、Privacy、Setup、Search；
- Private Admin；
- Export 和 Account Deletion 生命周期。

### P9 RC Hardening

- 自动化门禁、Windows/Tauri 验收、部署回滚和 RC 证据。

## v1.1 non-goals

- Cloud Model Gateway；
- Cloud Harness 和远程 Computer Use；
- 多人实时协作与企业组织；
- 订阅计费；
- 完整 Web Surface；
- 默认同步 Provider Secret；
- v2 DesktopSpace。
