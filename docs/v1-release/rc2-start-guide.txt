忆涟千言 v1.0.0-rc.2 快速开始

1. 运行“忆涟千言_1.0.0-rc.2_x64-setup.exe”。本候选安装包暂未签名，Windows 可能显示安全提示。
2. 首次打开后选择需要显示的模块，然后进入“开始使用忆涟”。模型服务用于 Chat、任务规划和 AI 审查；语音服务为可选项。
3. 在“设置 → 模型”填写 Provider、Base URL、模型名称和 API Key，保存后点击“测试连接”。密钥只写入系统凭据库，页面不会回显。
4. 普通 Chat 可点击麦克风；最终识别文字只填入输入框，不会自动发送，可先修改再发送。
5. Assistant 消息可手动播放。需要连续语音时，点击“与小涟语音对话”；会话会跨 v1 页面保持，直接讲话可打断播报。
6. 若模型未配置，Chat、任务规划和 AI 审查会显示“前往模型设置”，不会无限等待或静默失败。
