# 记忆图谱空间投影与文本证据

- 现有关系历史、记忆范围和删除重放保持原有边界。图谱读取当前有效记录及真实版本；已保存文本提取增加 1093 本地结构迁移，按来源记忆 ID、修订和摘引字符位置保存审阅结果，不建立重复记忆。旧数据库没有这些派生关系时不补写历史。
- 当前记忆和实体节点用同一世界布局。前景正投影从二维画布测得的平移、缩放和中心展开；三维实际使用逐条记忆版本层参与投影。历史版本使用轨迹，普通关系使用独立边。返回时逆向过渡，动作仅读，不修改数据库。
- 图谱读取复用当前索引。只对同一范围内有效、正文哈希和索引代次匹配的有限结果排序，不返回原始向量，不产生关系。未配置或不可用时按已有关系和文本布局；索引重试显式触发。文本提取单次只使用用户选定的已保存记忆，在候选里展示据以提取的原文；确认或纠正在来源仍有效时才保存。
- 验收分开记录原生桌面指针与布局、真实模型文本提取、回环模拟向量、Rust 治理和旧快照删除重放。成功记录分别位于 `target/native-memory-projection-release/result.json` 和 `target/native-memory-text-projection-delivery/result.json`。
