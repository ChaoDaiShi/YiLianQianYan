# 忆涟千言 UI 与全状态微交互优化：多阶段并行实施文档

> 日期：2026-10-16。读者：首次接触本仓库、需要明确文件和操作步骤的编码智能体。
>
> **执行说明：** 后续使用 `executing-plans` 按任务卡执行。本文中的并行，是工作包可以由用户指定的独立会话或开发者同时处理；不授权启动子智能体。本次只交付文档，不实施 UI，不提交、推送、合并或部署。

**目标：** 保留忆涟千言当前 Cyrene 视觉风格与业务能力，改善页面层级、信息密度、控件反馈、键盘操作和不同窗口尺寸下的可用性。

**架构：** 先固定主题变量、公共组件新增参数、文件所有权和验收口径，再并行优化七条界面工作线。各工作线继续消费现有 API、Store 和状态投影；集成负责人处理公共入口和样式顺序，验收负责人验证真实浏览器与桌面表现。

**技术栈：** React 18、TypeScript、Vite、Zustand、现有 CSS/Tailwind、Tauri；保持 Rust/Axum/Tokio/SQLite 后端。版本依据本次本地依赖清单，不代表查询了线上最新版本。

## 1. 先读这六条

1. Gemini 建议是输入材料，当前源码和已经落地的交互约定是实施依据。产品中文名统一为“忆涟千言”，不沿用原稿中的“意连前沿”。
2. 当前实际主题是 Cyrene 浅色、深色、跟随系统。`presets.ts` 中保留的其他主题定义不等于当前产品支持切换；本轮不恢复四主题系统。
3. 当前聊天与任务画布使用默认收起的右侧 ContextRail。保留显式展开与显式定位，不增加悬停自动开栏或悬停自动移动画布。
4. 不把本轮扩展成防御性开发。只处理 UI 所需的状态、布局、焦点、反馈与真实功能接线；现有审批、取消、密钥处理、SSE 语义继续沿用。
5. 文档中的新参数、新 CSS 文件和新验收用例均是**拟实施内容**，不是已实现能力。本轮产品验收统一为 `NOT TESTED`。
6. 任一工作包都要读“输入、可改文件、步骤、状态、验收、交付”六部分；禁止只读视觉描述后凭感觉修改整页。

## 3. 方案选择与取舍

| 方案 | 实际结果 | 本轮选择 |
|---|---|---|
| 按 Gemini 原稿逐字重做 | 会恢复旧主题、压缩现有字号、引入无数据的指标，并覆盖已有 ContextRail 行为 | 不采用 |
| 只统一颜色和圆角 | 改动少，但输入反馈、筛选、详情、任务状态和窄窗口问题没有完整处理 | 不采用 |
| 以现有源码为准分包优化 | 保留已完成能力，分别处理阅读、操作和状态，再统一接线验收 | **采用** |

采用第三种方案不代表每条 Gemini 建议都必须实现。00 中每项均给出采用、调整、保留已有或本轮不做的决定。

## 4. 阶段是验收点，工作线是并行单位

| 阶段 | 阶段成果 | 可同时推进的工作 | 退出条件 |
|---|---|---|---|
| P0 基线、任务和契约固定 | 基线 SHA、所有权、现有画面、公共参数确定 | I 核对入口；Q 准备状态场景；A 核对组件 | G0：没有待猜测的公共接口和文件归属 |
| P1 公共基础与独立页面开发 | 公共组件可用，各页面有可运行增量 | **A、B、C、D、E、F、G、Q 同时推进** | GA：A 的公共增量通过；各包提交局部证据 |
| P2 页面交互接线 | 页面接入公共组件，状态与动作对应真实数据 | 已满足依赖的工作包立即接线，其他包继续开发 | GB–GG：每包独立通过，不等全部页面一起验收 |
| P3 跨页与桌面集成 | 所有必需工作包进入同一候选，旧入口可用 | I 集成；Q 验证；各负责人修复自己问题 | GI：构建、完整页面矩阵、跨页操作通过 |
| P4 交付与证据归档 | 范围、结果、缺口和可复现证据清楚 | 文档整理与候选最终复核可并行 | GQ：必需项 PASS；桌面未验证必须单独说明 |

关键约定：B–G 可以在 P1 用现有组件完成页面布局和本地状态，不必等待 A 做完全部组件；**只有调用新增参数的接线步骤依赖 GA**。Q 从 P0 开始准备，不是最后才加入。

## 5. 本轮范围

- 深度优化 Gemini 原稿覆盖的 14 个页面，逐页对应 04–09。
- 同时检查 `/task-world/:graphId`、`/search`、`/account`、`/setup`，以及 `/sync`、`/privacy` 重定向受到全局样式变更的影响；这些入口不做业务重构。
- 处理默认、悬停、按下、键盘焦点、选中、禁用、加载、空列表、无搜索结果、请求失败、保存中、保存失败等可见状态。
- 支持现有浅色/深色/跟随系统、背景图片、减少动态效果、Windows 窗口缩放。
- 不建设 RAG、持久化会话置顶/改名接口、网络监控采集、任务百分比估算、全新权限体系、后台自动修复或新多智能体架构。
