# YiLianQianYan v0.9.0 Release Packaging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Do not use subagents for this plan.

**Goal:** Produce and verify the official unsigned Windows x64 NSIS installer for YiLianQianYan v0.9.0.

**Architecture:** Keep NSIS as the default platform bundle and expose macOS bundles only through explicit commands. A read-only version verifier guards release metadata, while a Windows release script runs quality gates, builds the installer, and emits a checksum. A separate smoke script validates isolated silent install/uninstall behavior.

**Tech Stack:** Tauri 2, Rust/Cargo, React/Vite/Vitest, npm, PowerShell, NSIS

## Global Constraints

- Release version is exactly `0.9.0`.
- The authoritative release artifact is an unsigned Windows x64 NSIS installer.
- Do not change Agent, MCP protocol semantics, approval, SSE, API schema, or database behavior.
- Do not add dependencies, auto-update, signing, notarization, MSI, or release CI.
- Preserve current user data and existing application identifier `com.yilianqianyan.desktop`.
- Use the existing Cyrene application icons; do not generate replacement artwork.

- [ ] **Step 2: Implement the Windows build script**
