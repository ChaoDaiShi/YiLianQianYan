# 证行产品入口与分阶段接线

> 状态：PLANNED。负责人：E。G0 后即可开发独立组件与状态；每个阶段以真实 API 和实际用户操作验收。沿用现有设计体系，不建立第二套工作台或画布。

## 1. 用户流程

```text
任务中心或现有画布的“从目标创建”
  → 输入目标、选择允许使用的已配置能力
  → 查看交付物、验收条件和候选计划
  → 处理缺少的参数或不支持的绑定
  → 确认目标与计划，保存到 Task World
  → 原有启动 / 审批 / 取消 / 执行历史
  → 打开成果，逐项查看验收证据
  → 如未达成：查看修复差异，确认后局部重跑
```

前端只负责呈现和提交用户输入。能力身份、编译结论、审批、验收 PASS 和修复影响范围由后端确定；不得用本地演示状态替代。

## 3. 按阶段交付

| 产品任务 | 可提前开发部分 | 接线条件 | 真实验收 |
|---|---|---|---|
| E1 目标输入和计划确认 | 使用契约夹具显示完整、缺输入、失败、保存中等状态 | B 草稿 API | 生成、编辑、保存、刷新重开 |
| E2 执行连接 | 既有 TaskWorld 导航和状态显示 | G1 | 真实 MCP 审批、拒绝、取消和参数传递 |
| E3 成果验收 | 条件列表、证据展开、人工确认 | C 报告 API | 打开真实文件；未达标不显示目标完成 |
| E4 修复审查 | 差异和影响范围视图 | D 提案/API | 确认补丁后重跑；旧版本冲突可恢复 |
| E5 产品收口 | 文案、键盘、窄窗口、加载体验 | G1–G3 | 真实 Windows Tauri 窗口内完整操作 |

夹具仅用于组件开发和测试，测试页面明确 simulated；不得在产品 API 不可用时默认展示成功计划、绿色验收或虚构成果。

## 4. 状态与交互要求

| 情形 | 用户看到什么 | 可执行动作 |
|---|---|---|
| 未配置模型 | 缺少模型配置及原设置入口 | 保留目标草稿，去设置 |
| 规划中 | 当前操作和取消按钮 | 取消后保留输入 |
| 无匹配能力 | 缺失能力/不支持原因 | 调整目标或由用户配置能力 |
| needs_input | 哪个节点、哪个参数、为何不能自动确定 | 固定值或现有绑定编辑，重新编译 |
| invalid | 明确诊断，无假成功图 | 编辑候选或主动重新生成 |
| ready_for_confirmation | 交付物、必需条件、工具和风险提示 | 确认保存；不是确认运行授权 |
| 保存中/失败 | 禁止重复提交，失败后保留全部草稿 | 查询确认状态或重试 |
| 等待审批 | 现有真实审批组件 | 批准、拒绝或取消 |
| 执行成功但目标未达成 | 分别展示运行与验收状态 | 查看缺失项，人工处理或请求修复 |
| human_pending | 固定 rubric 与证据 | 用户确认通过/不通过并说明 |
| 修复预算耗尽/结果未知 | 停止原因、已生成成果、实际轮次 | 用户接管；不自动扩大预算 |

规划请求取消后返回的旧响应不得覆盖新草稿；切换任务图后也不能写回另一图的面板。复用现有请求状态与 AbortSignal，做针对性竞态测试，不建立新的前端任务调度系统。

## 5. 画布兼容与易用性

- 保留 240×128 节点几何、用户布局、缩放、平移、选择和显式相机动作语义。展开证据、收到 SSE、保存参数均不自动 fitView。
- 新建图首次进入沿用现有初始化；同图刷新不重排。面板不能遮挡现有停止和审批操作。
- 主页面采用普通任务语言：目标、计划、待补充参数、成果、验收、修复建议。schema、execution ID、JSON 路径放在可展开详情，仅在用户修改绑定时展示必要信息。
- 复用当前 SSE 订阅更新执行状态；专项草稿/验收可在操作完成后拉取，不为本轮另建 SSE 总线。未知未来事件仍被忽略，不当作其他事件。
- 证据详情按需加载并显示来源时间，不能每次全图刷新拉取完整输出。

## 6. UI 验收脚本

| 编号 | 操作 | 必须验证 |
|---|---|---|
| U01 | 输入真实目标，生成后修改一项固定参数 | 草稿保存、编译重新计算，未直接执行 |
| U02 | 确认保存，刷新/关闭重开 | 图、绑定、目标契约和诊断持久化一致 |
| U03 | 运行两节点链并处理审批 | 下游真实参数对应上游结构输出；拒绝/取消不显示完成 |
| U04 | 输出不满足必需条件 | 运行成功和目标失败分别显示，能定位缺失项 |
| U05 | 查看文件和引用 | 打开实际产物，证据与报告一致 |
| U06 | 确认修复后并发修改图 | 旧提案明确失效，不能静默套用 |
| U07 | 模型/保存/验收 API 失败 | 草稿保留，错误可见，按钮恢复可用 |
| U08 | 缩放/平移后刷新执行状态并打开面板 | 位置、缩放、节点尺寸不变 |
| U09 | 1280×720 与 900×700 窗口、键盘导航 | 输入/确认/停止/审批可达，无内容截断和无法操作按钮 |
| U10 | 真实 Windows Tauri 安装候选 | 目标到成果完整操作；截图和执行记录关联 |

前端生产构建必需。浏览器测试不能替代 U10；组件夹具测试不能替代 U01—U06 的真实后端接线。没有可用真实窗口时记录 HUMAN_PENDING/NOT_TESTED，并说明对应缺口。
