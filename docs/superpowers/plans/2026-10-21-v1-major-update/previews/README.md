# v1 简洁版全页面预览

本目录包含 **20 张页面/关键状态概念图**。图片由内置 imagegen 生成，用于设计评审，不是当前软件截图，也不代表功能已实现。

打开 [可翻页图册](index.html)，通过左侧目录或方向键逐页查看。无需运行项目或启动服务器。图册只有查看、翻页和打开原图功能，图中业务按钮不可操作。

返回 [主开发文档](../../2026-10-21-v1-major-update.md) · [R2 产品与交互规格](../product-experience-r2.md)。

## 视觉与范围

- 统一昔涟浅紫/玫粉配色与深紫导航；保留当前四个主要导航入口。
- 主页默认收起会话列表与详情，用户可打开或固定历史；当前结果用文件行呈现。
- 复杂功能放在专项页面或按需展开区，不同时显示全部状态。
- 设置保留画布，默认显示分组；消息画布保留对话分支语义。
- 新增面板与既有路由已在表中区分。账号页的同步与隐私重定向不重复绘图。
- 这些图片覆盖各主要页面的代表状态；没有绘制每一个弹窗、空态、错误态和深浅色组合，这些交互仍受验收规格约束。

图片中的示例数字、日期、文件名、状态和文字是设计占位内容。实际实现需使用真实 API 与标准组件；图片中的个别字形或图标不应直接作为生产素材。工作空间 README 内容已经单独改为示例说明，避免把生成的技术命令当作项目事实。

生成方式：内置 imagegen，未使用 CLI。原始提示词与页面说明见 [prompts.json](prompts.json)。所有最终选定图片已复制到本目录，并核对原文件与副本的 SHA-256 一致。
