# 任务画布稳定行为契约

基线：`refactor/v1-architecture-semantic @ ce3dca2`。本轮仅修复画布行为，架构冻结。

## 用户拥有镜头

选择节点、打开 Inspector、执行刷新、语义保存、AI 审查及建议接受、服务端视图响应、窗口或面板尺寸变化，都不能移动镜头。跟随执行默认关闭，本轮不增加开关。

只有用户明确操作 Pan、Zoom、100%、适应全部、定位节点，才移动镜头。已有画布首次加载恢复保存视口；空画布使用 `(0, 0, 1)`，不自动适应全图。同一画布生命周期内本地视口优先，保存响应只更新文档版本。

## 用户拥有布局

状态变化是数据变化，不是布局变化。现有节点的位置、尺寸和选择交互保留，只更新标题、摘要、状态、执行结果等数据。新节点优先使用已保存位置，否则按图顺序分配确定位置；删除节点不移动其他节点。折叠分组隐藏成员，但保留其本地位置。

只有显式 Drag、Auto Layout、Restore 可以改变已有布局；本轮不新增 Restore 或 Undo 系统。自动布局立即在本地应用一次，然后保存，不因图版本变化再次运行。

## 拖动与保存

拖动立即显示本地位置，拖动结束后串行保存。等待保存时，语义刷新和旧服务端布局不能覆盖本地位置。遇到 `stale_view_revision`，读取最新文档，在最新版本上重放原修改，最多重试一次。仍冲突时显示“画布布局保存发生冲突，请重试”，保留本地视觉结果并提供重试。

## 稳定内容与可访问性

卡片固定为 240 × 128，预留执行信息区域，长标题与摘要截断。Execution Trail 使用 TaskGraph 节点顺序，状态只更新标记。轨迹选择和定位是独立按钮，定位具有可读标签。保留键盘选择、Delete、多选、焦点提示。
