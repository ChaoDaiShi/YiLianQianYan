# YiLianQianYan v0.8.0 Release Notes

## Added

- A frozen release boundary for trusted tool execution, resource grants, and desktop packaging.
- Server-created authorization evidence for network zones and managed process controls.
- Release-gate evidence checklist covering build, migration, SecretStore, isolation, MCP, and desktop lifecycle checks.

## Security

- Process authorization is limited to Agent-managed children. Explicit PID and all-host legacy grants are readable for migration but fail closed at execution.
- Network requests use one DNS resolution, pinned addresses, no proxy, no redirects, and trusted gateway-created zone evidence.
- Runtime security audit events preserve the initiating subject ID across policy, approval, execution, grant, and verification phases.

## Known boundaries

- The application-layer isolation controls are not claimed to be a complete host sandbox.
- A release is not considered ready until the real Windows Tauri package, install, launch, restart, SecretStore, upgrade, and isolation checks are executed and recorded in the checklist.
