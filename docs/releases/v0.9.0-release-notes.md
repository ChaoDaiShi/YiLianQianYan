# YiLianQianYan v0.9.0 Release Notes

## Release status

v0.9.0 功能开发已经冻结。Windows x64 NSIS 是本版本的正式安装包格式。安装包由本地受控构建流程生成，默认未进行商业代码签名；生成成功不等同于已签名。

## 主要更新

- 完成“昔涟 · 涟漪 / Cyrene Ripple”白天与夜间主题，统一桌面 Shell、透明 Surface、首页和对话体验。
- 首页以小昔涟、Agent 状态和中部 Composer 为操作中心；进入对话后切换为内容与任务效率优先的布局。
- 对话中可理解地展示真实 Tool 调用、执行结果、审批、错误、完成状态和技术详情，不展示模型私有推理。
- Task Center 与 Workspace 支持真实后台生命周期和筛选；历史任务、聊天执行记录和审批状态可恢复。
- Workflow、Memory、Knowledge、Skill、Plugin、Agent、Capability、Monitor、Logs 和 Settings 完成 v0.9 产品化界面。
- Skill、Capability Source 与 MCP 服务提供受现有安全边界约束的管理能力。
- 支持多个 OpenAI 兼容模型服务商档案、连接验证、激活切换和本地 Token usage 统计。
- 前端路由懒加载与渲染优化、后端空闲与监控开销优化已纳入本版本。

## 桌面行动可信度

网站或 GUI 应用只有在目标窗口真实出现并获得前台焦点后才报告打开成功。键盘输入必须绑定目标应用，并在输入动作及目标窗口状态得到验证后才能作为任务完成证据。仅启动记事本、浏览器或 QQ 进程，不再足以让 Agent 回答“已经完成”。

## Windows 安装包

- 格式：NSIS x64 installer
- 预期文件名：`忆涟千言_0.9.0_x64-setup.exe`
- 构建命令：`npm run build:windows`
- 校验：构建脚本生成同名 `.sha256` 文件
- 签名状态：未签名

MSI 不作为 v0.9.0 发布格式，因为既有 WiX 路径无法可靠编码中文产品名。安装前建议备份重要的本地应用数据；本版本不声明数据库降级兼容。

## macOS 边界

仓库提供显式 `.app` / `.dmg` 构建命令，但 Windows 发布验证不能替代真实 macOS 构建、权限、签名与公证验收。没有对应证据时，macOS 正式发布状态保持未验证。

## 已知限制

- 正式 Windows 安装包默认未签名，Windows 可能显示来源或信誉提示。
- 自动更新、发布 CI、Apple 签名与公证不属于 v0.9.0 打包范围。
- 应用层 Sandbox 不等价于完整操作系统隔离。
- 依赖审计结果以发布清单中的实际命令输出为准；发布冻结阶段不会为消除审计项擅自进行破坏性主版本升级。
- 可见窗口、非空白 UI、后端健康、核心 Agent 操作、关闭/重启与设置持久化仍需要对最终安装包进行人工验收。

## 依赖审计

发布准备已将 JS `@tauri-apps/plugin-shell` 升级到 2.3.5，并将 Rust `h2` 升级到 0.4.16，消除了审计中可通过兼容补丁修复的 critical / runtime vulnerability。生产前端仍有 5 项 moderate，来自 React Router 6 和语法高亮的嵌套 PrismJS；完整修复需要主版本迁移。Rust lockfile 中两项旧 `quick-xml` advisory 仅来自 Linux `xcb` 构建依赖，不进入 Windows x64 NSIS 运行时，发布清单记录了显式 ignore 和依赖链证据。
