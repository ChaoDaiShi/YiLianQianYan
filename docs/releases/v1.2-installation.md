# 忆涟千言 v1.2.0 安装说明

此版本提供 Windows x64 安装程序和 Apple Silicon Mac 安装包。Mac 包适用于 M1/M2/M3/M4，包括 MacBook Air M4、16GB 内存、512GB 硬盘。

## 给 Mac 用户

1. 下载 `YiLianQianYan_1.2.0_macos_arm64.dmg`，无需下载仓库源码。
2. 双击 DMG，把「忆涟千言」拖进「应用程序」。复制完成后推出磁盘镜像。
3. 从「应用程序」启动。无需安装 Xcode、Rust、Node，也无需执行任何编译或打包命令。
4. 这是临时签名（ad-hoc）、未经 Apple 公证的安装包。如果系统阻止打开，可在确认下载来源后前往「系统设置 → 隐私与安全性」使用「仍要打开」。无需关闭系统安全保护。
5. 屏幕录制、辅助功能权限仅在需要截图或控制电脑时按系统提示授予。AI 服务仍需配置你自己的服务信息。

备用文件 `YiLianQianYan_1.2.0_macos_arm64.app.zip` 内是相同的应用程序；选择 DMG 或 ZIP 其中一个即可。

## 给 Windows 用户

下载并运行 `YiLianQianYan_1.2.0_windows_x64-setup.exe`。安装包未配置发布者代码签名。

## 校验和验证范围

`SHA256SUMS-macos.txt`、`SHA256SUMS-windows.txt` 提供文件完整性校验。Mac 可在下载目录运行 `shasum -a 256 <文件名>`，Windows 可使用 PowerShell 的 `Get-FileHash <文件名> -Algorithm SHA256`。

Mac 的编译打包在 GitHub Actions 上进行，固定为 Apple Silicon 单架构、单个 Cargo 构建任务，关闭增量构建和调试符号。安装包不包含源码构建缓存、开发依赖或本地模型权重，不会在首次启动时自行编译项目。

发布工作流验证 Mac 磁盘镜像完整性、arm64 架构、临时签名、版本、隔离数据目录下的健康检查、60 秒空闲资源采样及进程退出；Windows 验证静默安装与卸载。资源采样记录主应用进程 RSS，不代表包括所有 WebKit 辅助进程的总内存，也不代表长时间任务峰值。

这些检查不等于已在朋友的 M4 上完成实际使用验收。实际 AI 服务、屏幕控制权限、长时间任务和该台 Mac 的运行峰值仍需在目标机器确认。
