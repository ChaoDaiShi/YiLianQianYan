# 附件预览与对话分支

聊天输入框支持上传、拖入和粘贴图片。添加文件后，附件卡片位于输入文字上方：图片展示内容缩略图，Word（DOCX）展示文件图标、文件名和类型卡片；点击卡片打开预览弹窗。

图片弹窗显示原图，DOCX 弹窗展示资源服务实际解析的正文，并可下载原文件。DOCX 预览不提供 Word 的分页排版。附件预览在本机加载，不依赖视觉模型服务是否已配置。

发送后，附件位于对应用户消息的文字气泡上方，靠右排列，并随该条消息一起滚动；刷新或重新进入会话仍可打开。回退用户消息时，恢复这条消息实际关联的附件。新分支继承所选回答之前的消息附件及其资源上下文。历史附件通过已记录的资源引用与上传所属轮次恢复到对应消息。此次位置修正移除了会话顶部的独立附件区；原文件和会话资源绑定保留。

左侧任务历史可切换“桌面”和“渠道”。QQ、微信、飞书等接入会话显示实际渠道来源。分支家族在列表中占一行，右侧分支图标显示路径数量；点击可查看主线、当前路径、分支起点和内容预览，切换路径或定位到画布。

画布支持桌面、渠道、全部三种来源筛选，以及会话定位。点击消息打开侧边详情和附件，点击回答的“创建分支”可在带有源回答的输入区提出新问题。Ctrl + Enter 发送，生成时可停止。详情区和输入区改变画布尺寸后，选中消息会保持可见。

此功能复用现有资源服务、普通对话执行、分支接口、停止机制与布局保存；没有引入新依赖。
