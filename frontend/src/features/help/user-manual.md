欢迎使用忆涟千言。手册可在软件内离线阅读，下面的入口会直接打开相应页面。

## 首次配置

打开[个人设置向导](/setup)可以填写称呼、交流偏好，选择记忆、屏幕、麦克风、文件工具和外部聊天模型权限。向导会保存草稿，点“保存并开始使用”后应用到当前本地资料。已有用户可从[权限设置](/setup?permissions=1)调整授权。

在工作空间详情的“页面”页签可以创建子页面、编辑块、查看修订或恢复内容。聊天中的表单和图表会记住已提交的状态，可从助手回复保存到页面。

1. 打开[模型设置](/settings?section=model)，选择服务商并填写自己的 API Key。软件会读取上游模型列表，选择需要使用的模型。使用自定义服务时，在地址选项中填写它的 API 地址。
2. 点「保存并使用」验证并启用模型。模型可用后，到[主页](/chat)发一条简单消息，确认收到回复。服务未提供模型列表时，可在「高级选项」填写模型 ID。
3. 搜索、语音和消息渠道可以按需配置。使用在线服务时，该功能所需的内容会发给你配置的服务。

[设置](/settings)默认打开收起的设置画布，可展开分类、管理节点或绑定资源。切换配置对象或重新打开设置画布会回到收起的总览，已保存的节点位置和连接会继续保留。从画布右上角的「更多操作」进入「快捷设置」，可以直接打开模型、语音、外观、导航和权限审批。其他服务和高级选项位于快捷设置的「更多设置」。

## 工作空间与对话

1. 到[工作空间](/workspaces)新建空间。Windows 桌面端可以先选本地文件夹，软件会用文件夹名预填名称。
2. 从空间详情点「开始对话」可直接使用该空间。也可在列表的 `⋯` 菜单设为默认工作空间，让以后新建的普通对话自动选用它。
3. 整理多个空间时，点「批量整理」，可跨搜索勾选，用「查看已选」核对。归档后可恢复，也可以确认删除空间入口。本地文件和历史记录会保留。

在空间的「文件」里打开支持的资料，点「用于学习」，就能预选该文件并填写学习主题。生成的笔记可以点「用于创作」打开文稿初稿，文稿会带回原笔记版本的链接。文稿也可以点「作为学习资料」，用已保存内容开启下一轮学习。最近的笔记和文稿可以在同一空间的「成果」里找到。

## 审批与停止

执行中如果出现待审批事项，先展开卡片核对工具、目标和参数，再决定批准或拒绝。也可以从左下方的[安全与审批中心](/system?card=approvals)查找待处理事项。

需要中断时，在当前对话或任务中点停止。已经完成的文件或外部操作仍会保留。操作结果未知时，先刷新状态或在目标软件里核对结果，再决定下一步。

## 安装与使用插件

1. 打开[能力 → 插件](/capabilities?category=plugin)，点「导入插件」，选择本地 ZIP、含 `plugin.json` 的插件目录，或公开 GitHub 仓库中的 ZIP。GitHub 导入需要填写完整的提交哈希。
2. 点「检查并生成预览」，核对插件名称、文件变更和权限，再确认安装或更新。完成后会自动打开该插件的详情，可在这里点「启用声明」。
3. 启用后，详情中的「插件入口」会显示该插件实际提供的功能和设置。需要查来源、权限或回滚版本时，展开「来源、权限与版本维护」。卸载和回滚都需要再次确认。

自己开发插件时，点「开发插件」，填写稳定的插件 ID、名称和版本，下载模板 ZIP。解压后编辑 `plugin.json` 和示例 `SKILL.md`，再用「本地插件目录」检查并导入。更新已有插件时沿用同一个 ID，并在预览中确认文件和权限变更。

插件可为 `contributes.features` 的入口声明 `placements`。`more` 显示在「更多」，`workspace` 显示在工作空间导航，可同时声明。已有入口默认显示在「更多」。

## 软件挂载与消息渠道

打开[软件挂载](/software)。左栏的「桌面软件」用于登记 Windows 程序、连接窗口和管理现有窗口会话。「消息渠道」下可选择 QQ、微信或飞书。

登记桌面程序时选择「通用 Windows 软件」，填写 EXE 路径并连接窗口。允许 AI 观察后，可以说“看看当前窗口有哪些选项”。如需读取正文或操作，分别开启对应许可。多个软件同时连接时，直接说登记名称，例如“在表单工具里勾选自动换行”。忆涟千言会按窗口实际提供的控件执行并核对结果。 自绘界面没有提供所需正文时，可单独允许「识别整个目标窗口的可见文字」。忆涟千言会在本机识别该窗口的一帧画面，再把识别文字提供给对话。

开启「后台监管」后，忆涟千言会在当前运行期间留意软件窗口变化。已允许观察的窗口还会监测软件提供的控件状态，允许读取正文时可监测文字变化。发现变化后可以在聊天页收到提示，也可以回到软件挂载查看最近一次提示。

添加账号后，在平台下选择会话。有多个账号时，先用账号切换框选账号。搜索框旁的 `⋯` 可打开渠道设置、回复预设和 QQ 的通讯录或机器人活动。

审阅回复时，点开待审阅草稿，编辑后点「审阅并批准发送」，在确认弹窗核对渠道、收件人和完整正文。若显示送达不明，先到相应平台核对。

左键单击系统托盘图标时，主窗口在前台就隐藏，在后台就带到前台，已隐藏或最小化就恢复。右键菜单中的主窗口操作会随可见状态显示「隐藏主窗口」或「显示主窗口」。

有通话或监控浮窗打开时，托盘菜单提供「隐藏浮窗」或「显示浮窗」。隐藏浮窗时，通话会继续。

## 浏览器密码箱

从内置浏览器的钥匙按钮打开「密码箱」。新建条目时填写网站地址、账号和密码。保存后默认未授权。

要让 AI 填充，先在对应条目点「授权填充」并核对网站，再在聊天中让 AI 对当前网页使用密码箱。授权绑定网站的协议、域名和端口，每个网站可授权一条凭据。填充后请在浏览器核对并提交登录。撤销授权会阻止后续填充，已经打开的网页和登录状态由浏览器管理。更换凭据需要重新授权。

## Harness 能力组合

在「能力 → Harness」的「工具组」里，可以查看默认系统组，或新建系统级和用户级的自定义组。系统级 Harness 使用系统级组，用户级 Harness 可以使用两种级别的组。

在「能力组合」里选择工具组、运行工作流、插件和对话智能体，保存后点「设为当前」。调用技能需要包含「加载技能」的工具组。技能或工作流来自插件时，还要选中来源插件。切换用于新对话轮次和新工作流。

工具组会限定可以调用的工具，审批和权限仍由执行网关处理。运行记录保存 Harness 版本，审批续跑沿用发起时的配置。个人主动助手和消息渠道继续使用各自的任务授权。

## 任务画布

从[能力 → 工作流 → 任务画布](/capabilities?category=workflow&workflow_tab=taskgraphs)可按首个节点或画布 ID 搜索。点「新建任务画布」打开空白画布，或点「规划任务画布」从任务目标生成计划。可验证规划支持先审阅计划，再保存为画布。从画布点「工作流列表」可返回任务画布标签页。

## 定时任务与唤醒

从「更多 → 定时任务」可查看计划和当前状态。启用后，任务在「挂起」状态等待定时或文件变化。触发登记后显示「唤醒」，开始执行后显示「运行」。审批或回答有各自的等待状态。

应用重启后，未到期的计划会继续等待。退出时尚未完成的执行会保留中断记录。暂停计划只暂停后续触发。「停止任务」或「停止委托」还会取消当前执行。定时触发需要应用保持运行。

## 记忆与资料

对话右上角的「执行与审批」显示本轮工作链路和审批、执行耗时。点「放大查看」打开带刻度的时间轴。相近节点会合并显示数量，点数量可放大查看该区间。也可以用加减按钮缩放，或点「聚焦执行」查看执行到答复的区间。点单个节点可看具体时间、记忆来源、完整答复或失败原因。

可以在对话里明确要求记住、更新或撤回信息，也可到[记忆](/memory)查看已保存内容。处理项目资料时，可将来源导入[知识库](/knowledge)，然后在对话中说明要使用哪份资料和要完成的任务。
